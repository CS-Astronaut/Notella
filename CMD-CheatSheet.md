
## Command line Cheat sheet


|      <mark style="background: #D2B3FFA6;">**$ Command $**</mark>      | <mark style="background: #FF5582A6;">explanation</mark> |
| :-------------------------------------------------------------------: | :-----------------------------------------------------: |
|                                **pwd**                                |                 print working directory                 |
|                                **cd**                                 |                    change directory                     |
|                                 cd -                                  |            go to the last working directory             |
|                                **ls**                                 |                       list files                        |
|                               **ls -a**                               |                    to list all files                    |
|                               **ls -l**                               |                   long listed format                    |
|                              **ls - h**                               |                 human readable numbers                  |
|                             **ls -altrh**                             |                         use it!                         |
|                                                                       |                                                         |
|                             man {command}                             |                   manual for command                    |

|                                                                       |                                                         |
|                            cat {filename}                             |                   to see file content                   |
|                            less {filename}                            |           cats out from top go down by enter            |
|                            head {filename}                            |            cats out first 10 lines of a file            |
|                            tail {filename}                            |            cats out last 10 lines of a file             |
|                                                                       |                                                         |
|                            mkdir {dirname}                            |                    make a directory                     |
|                         mv {name} {new name}                          |                      rename a file                      |
|                            mv {file} {dir}                            |                  move file to the dir                   |
|                            cp {file} {dir}                            |                  copy file to the dir                   |
|                            rm {file_path}                             |                       remove file                       |
|                              rmdir {dir}                              |                 remove empty directory                  |
|                             rm -rf {dir}                              |                    remove directory                     |
|                                                                       |                                                         |
|                        {command} > {filename}                         |      redirect the output of the command to a file       |
|                     grep 'string' {file location}                     |        searchs the string in the mentioned file         |
